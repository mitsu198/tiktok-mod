# TikTok MOD

A glassmorphism short-video social app prototype built with Expo + React Native.

## Run locally

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `i` / `a` to launch an available simulator.

## Current prototype

- Full-screen vertical video feed layout
- For You / Following header
- Like and follow interactions (local demo state)
- Search, create, inbox and profile navigation placeholders
- Dark glass UI with purple accents

## Roadmap

1. Connect authentication and user profiles.
2. Add video upload, storage and playback.
3. Implement likes, comments, follows, search and notifications with a backend.
4. Add profile themes, frames and other MOD-only appearance settings.

**Integration note:** This is an independent app prototype. TikTok's private APIs, internal recommendation feed, and native direct messages are not assumed to be available. Any TikTok account integration must use official APIs and their permitted scopes.
